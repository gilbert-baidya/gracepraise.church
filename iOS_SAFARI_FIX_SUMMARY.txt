====================================================
ROOT CAUSE IDENTIFIED
====================================================
The horizontal scroll issue on real iPhone devices was caused by:

1. ❌ CRITICAL: Multiple uses of "100vw" (viewport width)
   - Line 795: body { max-width: 100vw; }
   - Line 845: .devotion-controls, .devotion-container, etc. { max-width: 100vw; }
   - Line 851: .devotion-hero { max-width: 100vw; }

   iOS Safari BUG: 100vw includes scrollbar width, making it wider than actual viewport!
   This caused elements to be wider than screen, enabling horizontal scroll.

2. ⚠️ Missing global box-sizing
   - No global box-sizing: border-box
   - Caused padding/borders to add to element widths

3. ⚠️ Missing overflow-x: hidden on html/body
   - No global overflow prevention at root level

4. ⚠️ Flex/grid items with no min-width constraints
   - Flex children could expand beyond container

====================================================
FIXES APPLIED
====================================================

✅ FIX #1: Global CSS Safety (Lines 36-63)
Added at top of <style> block:

*,
*::before,
*::after {
  box-sizing: border-box;  /* All elements include padding/border in width */
}

html {
  width: 100%;
  max-width: 100%;
  overflow-x: hidden;  /* Prevent horizontal scroll at root */
}

body {
  width: 100%;
  max-width: 100%;
  overflow-x: hidden;
}

@supports (-webkit-touch-callout: none) {
  /* iOS Safari specific fix */
  body {
    overflow-x: hidden;
    position: relative;
  }
}

✅ FIX #4: Added flex/grid overflow prevention (Lines 948-966)
Final mobile safety patch:

  max-width: 100%;
  box-sizing: border-box;
}

.devotion-controls-row > *,
.date-strip-wrapper > *,
