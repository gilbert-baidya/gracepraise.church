🏠 Home Page Test Checklist

Test URL: http://localhost:8000/

⚠️ Instructions: Open the Home page in a new tab/window and perform these tests. Click each test button to mark as PASS or FAIL.

Desktop Tests (> 1024px width)

⏹ TEST 1: Header Visible

Expected: Header with GPBC logo, dark mode toggle, and navigation links is visible at top

Action: Look at the top of the page

⏹ TEST 2: Countdown Banner Below Header

Expected: Yellow countdown banner appears directly below header (NOT inside hamburger menu)

Action: Scroll page - countdown should stick below header

⏹ TEST 3: Navigation Links Visible (Desktop)

Expected: All nav links (Home, About, Ministries, etc.) are visible in header

Action: Check header - no hamburger menu on desktop

⏹ TEST 4: Dropdowns Work on Hover

Expected: Hovering over "About", "Ministries", "Devotion" shows dropdown menu

Action: Hover over dropdown links

Mobile Tests (< 1024px width or use browser dev tools)

⏹ TEST 5: Hamburger Menu Closed by Default

Expected: Page loads with NO menu visible, only hamburger icon (≡) visible

Action: Resize browser to mobile width or use dev tools - menu should be hidden

⏹ TEST 6: Hamburger Opens Menu

Expected: Clicking hamburger (≡) slides menu in from right

Action: Tap/click hamburger icon

⏹ TEST 7: Menu Icon Changes to X

Expected: Hamburger (≡) animates to X when menu opens

Action: Open menu and watch icon transform

⏹ TEST 8: Dark Overlay Appears

Expected: When menu opens, dark semi-transparent overlay appears over page content

Action: Open menu and check for dark background

⏹ TEST 9: Body Scroll Locked

Expected: With menu open, page content behind does NOT scroll

Action: Open menu, try to scroll page - should be locked

⏹ TEST 10: Menu Closes on X Click

Expected: Clicking X closes menu, icon animates back to ≡

Action: Click X icon to close menu

⏹ TEST 11: Menu Closes on Overlay Click

Expected: Clicking dark overlay closes menu

Action: Open menu, tap/click dark overlay area

⏹ TEST 12: Countdown NOT Inside Menu

Expected: Countdown banner is OUTSIDE menu, always visible below header

Action: Open menu - countdown should still be visible at top, not scrolling with menu

Logo & Navigation Tests

⏹ TEST 13: Logo Stays on Home Page

Expected: Clicking GPBC logo scrolls to top of Home page (does NOT navigate away)

Action: Click GPBC logo

⏹ TEST 14: Dark Mode Toggle Works

Expected: Clicking sun/moon icon toggles dark mode

Action: Click dark mode toggle button
