## ⚠️ CRITICAL RULES

1. **HEPTAGON LIMIT**
   - Maximum ONE heptagon per page
   - Represents Biblical number 7 (completeness)
   - Reserved for most important annual focus

2. **MOTION PHILOSOPHY**
   - All animations: 600-1200ms
   - Worship-like, never flashy
   - Must respect `prefers-reduced-motion`

3. **SCRIPTURE PRIORITY**
   - Design frames content, never overpowers
   - Text must be readable (WCAG AA minimum)
   - White space is sacred

4. **SHAPE MEANING**
   - Every shape has purpose
   - Don't mix randomly
   - Follow page rhythm guidelines

5. **ACCESSIBILITY**
   - Keyboard navigation required
   - Color contrast enforced
   - ARIA labels mandatory

## 🐛 TROUBLESHOOTING QUICK FIXES

### Shapes not showing?
```bash
# Check files exist
ls -la shape-system.css shape-system.js shape-sections.html

# Check CSS is linked in <head>
grep "shape-system.css" index.html

# Check JS is linked before </body>
grep "shape-system.js" index.html
```

### JavaScript not working?
```javascript
// Open browser console (F12)
// Look for errors
// Verify jQuery is loaded (for existing sliders)
```

### Motion too fast/slow?
```css
/* Edit shape-system.css */
:root {
    --motion-slow: 1500ms;    /* Increase for slower */
    --motion-medium: 600ms;   /* Decrease for faster */
}
```

## 🎓 TRAINING NOTES

When teaching content managers:

1. **Shape Selection**
   - Ask: "What's the purpose of this content?"
   - Match purpose to shape meaning
   - One dominant shape per page

2. **Content Guidelines**
   - Scripture first, always
   - Short paragraphs (3-4 lines)
   - Clear call-to-action
   - High contrast text

3. **Heptagon Rule**
   - Emphasize: ONE per page maximum
   - Reserved for most important focus
   - Annual themes only

4. **Testing Checklist**
   - Mobile device (not just browser resize)
   - Keyboard navigation (Tab, arrows)
